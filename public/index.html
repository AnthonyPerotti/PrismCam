Controle PTZ via API

Use estes endpoints em scripts/hotkeys do OBS para controlar o PTZ:

POST /api/ptz/{id}/move Mover câmera
POST /api/ptz/{id}/stop Parar movimento
POST /api/ptz/{id}/zoom Controlar zoom
POST /api/ptz/{id}/preset/goto Ir para preset
Exemplo com curl: 
curl -X POST http://localhost:4000/api/ptz/{camera-id}/preset/goto \
  -H "Content-Type: application/json" \
  -d '{"preset": 1}'
